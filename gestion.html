Configuración Impresora Térmica POS-80C
Impresora detectada: POS-80C — Ticket 80mm — USB
Driver: POS Printer Driver V7.17 · Resolución: 203 dpi

📋 Pasos de instalación (Windows):

1. Ejecutar POS_Printer_Driver_Setup_V7_17_02.exe como administrador → clic Sí
2. Aceptar el acuerdo de licencia → Next
3. Dejar la ruta por defecto C:\POS Printer Driver V7.17 → Next → Next → Install → Finish
4. El programa se abre automáticamente. Conectar la impresora por USB y seleccionar "Check USB Port" → elegir POS-80C → tildar "Set Default Printer" → "Install Now"
5. Cuando pregunte si configurar el puerto → Sí → en la lista elegir el puerto USB001 → Apply → OK
6. Ir a Propiedades de la impresora → pestaña General → "Print Test Page". Si imprime → ¡listo! ✅
⚠️ Si no aparece en Dispositivos e Impresoras:
Panel de control → Agregar impresora → "Agregar impresora local" → LPT1 → "Usar disco..." → Browse → C:\POS Printer Driver V7.17\Windows NT x86 (o x64) → elegir el .inf → seleccionar POS-80C → Siguiente → Finalizar → configurar puerto USB001.
🖨️ Para imprimir desde el sistema:
Generá una venta → en el comprobante que aparece → clic en "Imprimir Ticket".
El sistema genera automáticamente el formato para ticket 80mm con todos los datos fiscales.
